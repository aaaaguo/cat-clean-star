# Cat Clean Star

A Processing project based on the assigned keywords:
- Subject: Cat
- Action: Clean
- Object: Star

## User Story
As a player, I want to control the cat to move towards and clean dirty stars, so that I can interact with the animation and complete the cleaning task.

## Features
- Arrow-key movement for the cat
- Canvas boundary constraints
- Five dirty stars
- Cat-star collision detection using distance calculation
- Dirty-to-clean state change
- Cleaned-star progress counter
- Prevention of repeated cleaning/counting
- Completion message after all five stars are cleaned
- R key resets the game

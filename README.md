# Cat Clean Star

## Project Keywords
- Subject: Cat
- Action: Clean
- Object: Star

## Project Overview
Cat Clean Star is a Processing interaction project. The player controls a cat with the arrow keys and moves it towards dirty stars. When the cat touches a dirty star, the star changes to a clean state and the cleaned count increases. A cleaned star cannot be counted again. After all five stars are cleaned, the program displays a completion message. Pressing R restarts the game.

## User Story
As a player, I want to control the cat to move towards and clean dirty stars, so that I can interact with the animation and complete the cleaning task.

## Acceptance Criteria
1. Pressing the arrow keys moves the cat in the corresponding direction.
2. The cat remains inside the canvas.
3. When the cat touches a dirty star, the star changes to a clean state.
4. A star that has already been cleaned cannot be counted again.
5. The cleaned-star count increases only when a new star is cleaned.
6. When all five stars are cleaned, a completion message is displayed.
7. Pressing R resets all stars and the cleaned-star count.

## Definition of Done
- The code runs without compilation or runtime errors.
- The acceptance criteria have been tested.
- The completed code is committed to GitHub.
- The relevant GitHub Issue is updated after completion.
- The final behaviour matches the user story.

## Controls
- Arrow keys: Move the cat
- R: Restart the game
